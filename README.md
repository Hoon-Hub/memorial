# 모바일 부고장

GitHub Pages용 정적 HTML/CSS/JavaScript 부고장입니다.

- 장례 정보는 `config.js`에서 수정합니다.
- 아직 확인되지 않은 항목은 비워두세요.
- **확정 전에는 GitHub Pages를 활성화하지 마세요.** Public 저장소의 소스코드는 공개됩니다.
- 배포할 때: Settings → Pages → Deploy from a branch → `master` / `(root)` → Save.
- Pages는 접근 제어 기능이 아닙니다. `noindex`는 검색 노출 방지 보장이 아닙니다.
